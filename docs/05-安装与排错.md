# 05 安装与排错

## 安装

```
1. 复制目录到任意位置
2. cp config.example.json config.json 并按需改
3. node bin/init.mjs
4. 每个接活会话挂一次巡检提醒（见 docs/02）
```

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `node bin/take.mjs` 说没有信 | 信箱目录没建 / 接收方名不匹配 | 跑 `node bin/init.mjs`，核对 config.json 的 windows |
| 工单 take 报退出码 6 | 手上已有 doing 的单 | 先 submit 或 block 再 take |
| 巡检不触发 | 提醒跟会话走，换会话丢了 | 重挂（docs/02） |
| 频道没记录 | channelFile 路径不对 | 检查 config.json 的 channelFile |
| 中文乱码 | Windows 控制台代码页 | `chcp 65001` 或设 `$OutputEncoding` |

## 验证安装是否成功

```
node bin/selfcheck.mjs
```

会检查：目录结构、config 可解析、信箱可写、频道可追加、扫描脚本可跑。
