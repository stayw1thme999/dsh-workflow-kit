# 02 巡检 prompt（挂到每个接活会话）

把下面整段作为提醒内容，间隔 20 分钟：

```
自动巡检（本接收方自挂）：
1) node bin/take.mjs --window <接收方名>        收自己接收方的信
2) node bin/list.mjs --window <接收方名>        有 doing 就开工，每 10 分钟 node bin/progress.mjs --window <接收方名> "在做什么"
3) 队列空则 node bin/wo-take.mjs <接收方名>     自取工单开工（取到后 node bin/wo-submit.mjs <id> "<证据>"）
4) 做完/卡住按 docs/03-反馈链路.md 发频道
全程守住红线（不花钱/不删除/不对外提交/不改生产/不承诺）
每轮结果一行写进 <workspace>/data/channel.jsonl
```

## 为什么必须自挂

DSH 的定时提醒**跟会话走，不跟接收方名走**：

- 换新会话 = 提醒全丢，必须重挂
- 直接改调度存储文件无效（只是内存镜像，会被运行时覆盖）

## 三件套自愈

每轮巡检第〇步先核对：

```
□ 20 分钟巡检提醒在
□ 7:00 早间提醒在
□ 17:00 晚间提醒在
```

缺了立刻重挂，并在频道记一行「巡检自愈」。
